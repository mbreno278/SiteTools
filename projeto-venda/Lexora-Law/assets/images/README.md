# Images

This folder is intentionally empty in the base package.

The template uses CSS-generated monograms and gradient placeholders for:

- Attorney portraits
- Hero artwork
- Article cards
- Profile pages

## Recommended next steps

1. Add optimized images (WebP preferred, with JPEG fallback) here.
2. Replace the placeholder elements in the HTML with `<img>` tags that include descriptive `alt` text.
3. Ensure every photograph has a commercial license suitable for resale of the template and for client websites.
4. Keep file sizes reasonable (hero images ideally under 200–300 KB after compression).

Suggested naming:

```
attorney-alexandra-morgan.jpg
attorney-james-whitaker.jpg
attorney-sophia-chen.jpg
hero-office.jpg
article-business-law.jpg
...
```
