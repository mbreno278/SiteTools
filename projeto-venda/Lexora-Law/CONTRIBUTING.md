# Contributing / Custom Development Notes

This is a commercial static HTML template. End users are expected to customize it for their own projects under the terms of the commercial license.

If you are the original author maintaining the product:

1. Keep the CSS design tokens as the single source of truth for colors.
2. Preserve the zero-build philosophy unless a clear buyer benefit justifies adding a simple build step.
3. Document any new features in the CHANGELOG and the relevant documentation files.
4. Test theme switching, mobile navigation, forms, and search after structural changes.
5. Re-run a basic HTML/CSS validation and check relative paths before packaging a new version.
