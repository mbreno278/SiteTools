# Deployment Checklist

- [ ] All fictional brand, attorney, and contact content replaced
- [ ] Forms connected to a secure backend or form provider
- [ ] Privacy Policy and Terms reviewed by qualified counsel for your jurisdiction
- [ ] Page titles, meta descriptions, and Open Graph tags updated
- [ ] `sitemap.xml` updated with real canonical URLs
- [ ] `robots.txt` reviewed
- [ ] Favicon and brand mark replaced
- [ ] Images optimized and properly licensed
- [ ] HTTPS enabled
- [ ] 404 page configured on the host
- [ ] Mobile navigation, theme, search, and forms tested on the live domain
- [ ] Lighthouse / performance check performed
- [ ] Legal advertising rules of the target jurisdiction reviewed
