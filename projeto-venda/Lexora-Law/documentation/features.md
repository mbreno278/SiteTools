# Features and Limitations

| Feature | Included | Notes / Limitation |
|---------|----------|--------------------|
| Light / Dark theme | Yes | Preference saved in localStorage (may be blocked by browser settings) |
| Responsive navigation | Yes | Static links |
| Demo search | Yes | Fixed sample index of 5 articles — not a full CMS search |
| Contact & Consultation forms | Yes | Client-side validation only; no data is transmitted or stored |
| FAQ accordion | Yes | Static content |
| Article table of contents | Yes | Auto-generated from h2/h3 on article pages |
| Reading progress bar | Yes | Visual only |
| Back to top | Yes | Smooth scroll (respects reduced-motion) |
| Style guide | Yes | Colors, typography, buttons, and components |
| SEO foundations | Yes | Titles, descriptions, basic Open Graph, sitemap & robots examples |
| Accessibility basics | Yes | Skip link, focus-visible, ARIA on interactive elements, reduced-motion |
| Backend / CMS | No | Pure static HTML |
| User authentication | No | — |
| Payment / booking | No | — |
| Multi-language | No | English only in this edition |

The template is intentionally lightweight so it can be hosted anywhere and customized without a build pipeline.
