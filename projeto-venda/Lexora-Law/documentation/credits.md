# Credits and Third-Party Assets

## Original work

- Design system, layout, and interactions: Lexora Law template
- Brand mark SVG: original

## Fonts

- **DM Sans** and **Playfair Display** are loaded from Google Fonts via CSS `@import`.
- They are **not** bundled in the package.
- Before redistributing local font files, verify the current license terms of each typeface and the rules of the marketplace you are selling on.

## No third-party libraries

- No JavaScript frameworks or UI libraries are included.
- No icon font or external icon library is used (inline SVG only).
- No photographic assets are bundled.

## Placeholders

All attorney portraits, article imagery, and monogram art are CSS-generated placeholders. Replace them with properly licensed commercial photography before publishing a live site.
