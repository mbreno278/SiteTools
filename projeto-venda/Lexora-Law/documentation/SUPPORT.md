# Support Policy

**Lexora Law Template — Version 1.2.0**

## What is covered

For a period of **six (6) months** from the date of purchase we provide support for:

- Installation and local preview issues
- Broken links or missing assets in the original package
- JavaScript or CSS defects that prevent core features from working as described
- Clarification of documentation

## What is not covered

- Custom design or development work
- Content writing or legal text review
- Integration with third-party services beyond the examples provided
- Hosting configuration, DNS, SSL, or server-side issues
- Modifications made by the buyer that introduce new bugs
- Legal advice or compliance with advertising/privacy regulations
- Browser versions older than the current major releases of Chrome, Firefox, Safari, and Edge

## How to request support

1. Use the official support system of the marketplace where you purchased the template.
2. Include your purchase code / order number.
3. Describe the issue clearly and, when possible, provide:
   - Browser and OS
   - Steps to reproduce
   - Screenshots or console errors

We aim to respond within 1–2 business days.

## Updates

Minor bug-fix updates may be released during the support period. Major new features are not guaranteed under the standard support window.
